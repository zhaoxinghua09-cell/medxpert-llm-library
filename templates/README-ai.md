# 给 AI 的使用说明

## 你可以做什么
- 基于本库内容回答问题，但**必须标注信息来源文件**
- 帮助整理、摘要、检索知识库内容

## 你绝不能做什么
- **本库没有的信息，直接说"库中未找到"，禁止编造**
- 涉及法规/标准的内容，遵守"以现行版为准"原则，不臆断
- 不泄露、不扩散任何库内的敏感或受限内容
- 不执行删除、重命名等破坏性文件操作（除非用户明确要求且确认）

## 回答格式建议
1. 先给结论，再给依据
2. 引用时标注来源文件（如"来源：01-法规/GMP-2025.md"）
3. 信息不全时，说明缺什么、哪里能找到

## 元信息说明
每个文件头部有 YAML frontmatter（title/source/date_added/status/level/tags），
回答时可参考这些字段判断内容的新旧与可信度。
